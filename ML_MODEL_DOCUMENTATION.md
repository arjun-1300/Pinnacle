## 2. Approach 1: Baseline Deterministic Rule Engine

### 2.1 Overview & Architecture
The baseline represents conventional hospital Electronic Health Record (EHR) threshold alerting, patterned after standard Modified Early Warning Score (MEWS) and National Early Warning Score (NEWS2) systems.

* **Monitoring Classification Rules**:
  $$\text{Risk}(V) = \begin{cases} 
  \text{Critical}, & \text{if } \text{SpO}_2 < 90\% \lor \text{HR} > 130 \text{ bpm} \lor \text{Temp} > 39.5^\circ\text{C} \\
  \text{Warning},  & \text{if } \text{SpO}_2 < 95\% \lor \text{HR} > 95 \text{ bpm} \lor \text{Temp} > 37.5^\circ\text{C} \lor \text{SBP} > 130 \text{ mmHg} \\
  \text{Normal},   & \text{otherwise}
  \end{cases}$$
* **Medication Rules**: Fixed string-match lookup over a static set of pairwise drug contraindications (`INTERACTION_RULES`).

### 2.2 Training
* **Training Data**: None (0 samples; hand-calibrated clinical threshold values).
* **Training Time**: 0.0 seconds.

### 2.3 Empirical Performance (Evaluated on $N = 1,000$ held-out clinical samples)
* **Macro-F1 Score**: `0.9242`
* **Critical Recall**: `0.8849`
* **Accuracy**: `92.20%`

## 3. Approach 2: Supervised Machine Learning Models

Approach 2 equips the system with dedicated, high-performance Machine Learning models specifically built and calibrated for the two most critical agents in the clinical workflow.

### 3.1 Model 1: Monitoring Agent Physiological Risk Classifier (`model.joblib`)

#### Objective
To predict multidimensional patient risk tier (`Normal`, `Warning`, `Critical`) and output calibrated continuous probability vectors directly from real-time vital streams:
$$\mathbf{x} = [\text{HR}, \text{SpO}_2, \text{Temp}, \text{SBP}] \in \mathbb{R}^4$$

#### Training Methodology
1. **Dataset**: 3,000 synthetic patient records generated by `SyntheticDataGenerator(seed=42)` drawing from multivariate clinically grounded Gaussian distributions:
   - $\text{Normal}: \mu = [75, 97, 36.8, 120], \sigma = [8, 1, 0.3, 8]$
   - $\text{Warning}: \mu = [100, 94, 37.9, 138], \sigma = [10, 1.5, 0.4, 10]$
   - $\text{Critical}: \mu = [128, 88, 39.2, 165], \sigma = [14, 3, 0.6, 15]$
2. **Stratification & Class Balancing**:
   - Critical: 1,019 samples (34.0%)
   - Normal: 1,006 samples (33.5%)
   - Warning: 975 samples (32.5%)
3. **Model Architecture**:
   - Algorithm: `RandomForestClassifier` (Ensemble of 100 de-correlated Decision Trees)
   - Splitting Criterion: Gini Impurity
   - Class Weighting: Balanced ($w_j = \frac{N}{K \cdot n_j}$)
   - Output: Softmax probability distribution $P(y = c \mid \mathbf{x})$ across classes
4. **Serialization**: Serialized to `model.joblib` via `joblib.dump()`.

#### Feature Importances (Gini-Based Contribution)
- **SpO2 (Blood Oxygen Saturation)**: **41.8%** (Dominant predictor of respiratory decompensation)
- **Heart Rate**: **28.4%** (Tachycardia / Bradycardia hemodynamics)
- **Body Temperature**: **17.9%** (Sepsis and systemic hyperthermia)
- **Systolic Blood Pressure**: **11.9%** (Hypertensive crisis and vascular collapse)

#### Performance Metrics (Held-out Test Set $N = 1,000$, Seed 99)
* **Macro-F1 Score**: **0.9902** (+0.0660 improvement over Baseline)
* **Critical Recall**: **0.9934** (Caught 302 of 304 critical patients; only 2 edge cases missed)
* **Overall Accuracy**: **99.00%**

### 3.2 Model 2: Medication Agent Drug-Drug Interaction (DDI) Classifier (`ddi_model.joblib`)

#### Objective
To classify the adverse pharmacodynamic interaction severity between patient active medications and newly proposed candidate therapies into:
$$y \in \{\text{HIGH}, \text{MODERATE}, \text{NONE}\}$$

#### Training Methodology (`train_ddi_model.py`)
1. **Dataset Generation**: 2,500 pairwise pharmacological interaction feature vectors generated across 11 major drug classes:
   - Anticoagulant (`warfarin`, `heparin`, `apixaban`)
   - Antiplatelet (`aspirin`, `clopidogrel`)
   - NSAID (`ibuprofen`, `naproxen`, `ketorolac`)
   - ACE-Inhibitor (`lisinopril`, `ramipril`)
   - ARB (`losartan`, `valsartan`)
   - Biguanide (`metformin`)
   - Statin (`atorvastatin`, `simvastatin`)
   - Beta-Blocker (`metoprolol`, `atenolol`)
   - Analgesic (`acetaminophen`)
   - Antibiotic (`amoxicillin`, `azithromycin`)
   - PPI (`omeprazole`, `pantoprazole`)
2. **Feature Engineering**:
   - 11-dimensional symmetric one-hot class vector: $\mathbf{v}_{\text{class}} = \mathbf{e}_{A} + \mathbf{e}_{B}$
   - Bleeding synergy indicator: $\mathbb{I}_{\text{hemorrhage}} \in \{0, 1\}$
   - Nephrotoxicity / Renal synergy indicator: $\mathbb{I}_{\text{renal}} \in \{0, 1\}$
   - CYP450 metabolic pathway competition: $\mathbb{I}_{\text{CYP}} \in \{0, 1\}$
   - Gaussian feature perturbation noise ($\mu = 0, \sigma = 0.02$) to model clinical dosing variance.
3. **Model Architecture**:
   - Algorithm: `RandomForestClassifier` (120 estimators, max depth 12)
   - Stratified Train/Test split: 75% train (1,875 samples), 25% test (625 samples)
   - Cross-Validation: 5-Fold Stratified Cross-Validation
4. **Serialization**: Saved to `ddi_model.joblib` with class metadata and feature names.

#### Performance Metrics
* **5-Fold Cross-Validation Macro-F1**: **1.0000 $\pm$ 0.0000**

## 4. Approach 3: Hybrid Neuro-Symbolic Agentic Architecture

### 4.1 Concept & Dual-Verification Architecture
Approach 3 integrates the best of all worlds:
1. **Statistical Learning (ML Classifiers)**: Fast, deterministic, calibrated probability scoring and feature importance ranking for Monitoring and Medication agents.
2. **Generative Intelligence (Google Gemini LLM)**: Deep clinical reasoning, pathophysiological narration, multi-condition synthesis, and candidate therapeutic planning.
3. **Deterministic Hard Invariant (Safety Agent)**: Programmatic interceptor guaranteeing that no LLM hallucination or contraindicated drug can ever be administered.
